# 01 — Foothill Quiet Luxury

**Role:** Existing AGS concept and the recommended default for a trusted Dehradun brokerage.

- **Audience:** Families, local buyers, NRIs, and premium residential clients.
- **Visual thesis:** Landscape-led calm; the home belongs to the foothills rather than overpowering them.
- **Palette:** Forest `#15211E`, paper `#FBFAF6`, stone `#ECE9E1`, copper `#C98555`.
- **Typography:** Cormorant Garamond display (64–124 px); Manrope UI/body (14–18 px).
- **Layout:** Cinematic hero, raised filter bar, spacious editorial sections, three-column cards.
- **Motion:** Slow image scale, 16–24 px content rises, restrained hover lift.
- **Conversion:** Property search first; WhatsApp and visit scheduling second.
- **Best for:** A professional local brand that needs premium positioning without implausible luxury claims.
- **Avoid:** Gold gradients, fake achievement counts, dense filter controls in the hero.
- **Tools:** Next.js, CSS/Tailwind, responsive images, optional map module.
