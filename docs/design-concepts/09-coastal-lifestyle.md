# 09 — Coastal Lifestyle

- **Audience:** Holiday-home, resort, relocation, and lifestyle buyers.
- **Concept:** Airy, optimistic discovery built around place, light, and an easy enquiry path.
- **Palette:** Deep sea `#063D4C`, aqua `#46B9B1`, coral `#F27E62`, sand `#F7EEDC`.
- **Typography:** Soft geometric sans; relaxed serif italic accents; 56–100 px display type.
- **Layout:** Full-bleed panoramas, curved sections, locality cards, lifestyle itinerary.
- **Motion:** Horizontal galleries, gentle wave-like easing, subtle image drift.
- **Conversion:** Plan a discovery visit, explore neighbourhood guide, talk on WhatsApp.
- **Best for:** Leisure-led homes where the destination is as important as the building.
- **Risk:** Keep practical facts prominent; lifestyle imagery must not obscure access, price, or legal status.
- **Tools:** Responsive imagery/video, map guide, itinerary CMS, optional weather/tide integrations only if requested.
