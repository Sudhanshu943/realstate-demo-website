# 04 — Architectural Grid

- **Audience:** Construction firms, architects, developers, and project-led real-estate brands.
- **Concept:** Treat every project like a case study with drawings, materials, and design intent.
- **Palette:** Blueprint blue `#18324A`, concrete `#D9D7D0`, white, safety orange `#F26A2E`.
- **Typography:** Swiss grotesk; uppercase 12–14 px labels; 56–96 px geometric headlines; monospace details.
- **Layout:** Visible 12-column grid, numbered project index, specification tables, plan overlays.
- **Motion:** Grid-line reveals, plan/detail crossfades, precise 180–240 ms transitions.
- **Conversion:** Brochure request, construction consultation, project enquiry.
- **Best for:** Businesses where construction credibility matters as much as resale listings.
- **Risk:** Over-designed grids can reduce readability on mobile; collapse into a disciplined single column.
- **Tools:** CSS Grid, SVG floor plans, PDF brochure pipeline, optional BIM-to-GLB workflow.
