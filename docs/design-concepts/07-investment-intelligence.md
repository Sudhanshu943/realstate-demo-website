# 07 — Investment Intelligence

- **Audience:** Investors, landlords, commercial buyers, and analysts.
- **Concept:** Evidence first: yields, cash flows, locality comparisons, and risk disclosures.
- **Palette:** Midnight `#071825`, slate `#203442`, mint `#57D3A2`, amber `#F5B84B`.
- **Typography:** Modern sans with tabular numerals; 44–64 px headlines; 14–16 px UI; 12–13 px chart metadata.
- **Layout:** KPI strip, comparison table, chart cards, compact property rows, downloadable memo.
- **Motion:** Animated values only once, chart hover states, drawer transitions.
- **Conversion:** Request investment memo, speak to advisor, compare assets.
- **Best for:** Commercial and investment property discovery.
- **Risk:** Clearly label assumptions and never present demo yields as facts.
- **Tools:** Recharts/ECharts/Visx, server-validated data, PDF export, currency/date formatting.
