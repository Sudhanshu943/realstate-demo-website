# 03 — Map-first Property Finder

- **Audience:** Buyers comparing many localities, budgets, or commute zones.
- **Concept:** The map is the primary workspace; listings update beside it.
- **Palette:** Navy `#0B1F33`, cloud `#F4F7FA`, cyan `#2F80ED`, green status `#1A8F5C`.
- **Typography:** Inter/system sans; 42–64 px hero, 14–16 px dense UI, tabular numerals for prices.
- **Layout:** Sticky filter rail, split map/list, clustered pins, bottom-sheet cards on mobile.
- **Motion:** Pin/list synchronization, drawer easing, skeletons—not decorative parallax.
- **Conversion:** Save search, compare, schedule visit from selected card.
- **Best for:** Large or frequently changing inventory.
- **Risk:** Map APIs add cost and performance work; provide list view and accessible controls.
- **Tools:** Google Maps JS or Mapbox GL JS, marker clustering, geocoding, URL-synced filters.
